**Sends your stage display to any tablet.**

A tidying release after the first public sweep. Nothing new to learn; a lot that now behaves as you would expect.

### What changed

- **Quitting always asks first.** Cmd+Q now asks before stopping every tablet, the same as closing the window and the menu bar Quit already did. It also counts tablets that are waiting for a picture, not only the ones showing one.
- **Check for updates no longer freezes the room.** The dialog comes to the front and no longer stops the words page while it is open.
- **Screen Recording is explained properly.** The banner now says to allow it and then quit and reopen Ministry Stage, and no message points at a banner that has already gone.
- **The Local Network prompt is documented.** macOS 15 and later ask for it; refusing it quietly stops the words page and the clicker, and the guide now says so.
- **The guide is current.** It covers the menu bar icon, Check for updates, the fact that closing the window quits the app, and a plain account of what the app keeps about each tablet and how to delete it.
- **Tablets are named after places.** Stage left, Sound desk, Lectern: names are kept until you tap Forget, so they should describe where a tablet sits rather than who is holding it.
- **The licence travels with the app.** The disk image and the app itself now carry the licence and the third-party notices.

### What you need

- An **Apple Silicon** Mac (an M-series chip, or the A18 in a MacBook Neo). Intel Macs cannot run it.
- **macOS 12** or later.
- **ProPresenter** on the same Mac, and everything on one wifi.

### Updating from 0.2.0

Download this disk image and drag Ministry Stage into Applications over the old one. Your approved tablets and settings carry across. If you have 0.2.0 open, **Help → Check for updates** will now tell you about this version.

### A word of warning

This is a young app, written for one church and shared in the hope it helps yours. Please try the words page with ProPresenter open **before** you rely on it in a service.
